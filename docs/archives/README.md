# Archives de la documentation

Un document qui ne décrit plus ni ce qui existe ni ce qui est décidé est déplacé ici, jamais supprimé (git garde l'historique, mais un fichier archivé reste lisible sans fouiller l'historique).

Règles :

- Un document entièrement dépassé est déplacé ici avec `git mv`, en gardant son nom ; une ligne est ajoutée au tableau ci-dessous (date, raison, document qui le remplace), et les liens qui pointaient vers lui sont mis à jour.
- Un passage dépassé dans un document encore valable est corrigé sur place, avec la date du changement (« Remplacé le 13/11/2026 : … »), pour garder la trace de la décision.
- Les fiches de `docs/decisions/` ne sont jamais archivées : une fiche remplacée garde son texte et renvoie à la nouvelle.
